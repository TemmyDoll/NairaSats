# Contributing

Thanks for considering a contribution. This project is a sample archetype for the LAB Open Source Builders Fund and welcomes real contributions from builders exploring what fundable work looks like.

## Getting started

1. Fork the repo
2. Create a feature branch
3. Make your changes with clear commits
4. Add tests where relevant
5. Open a pull request

## What we welcome

- Bug fixes and stability improvements
- Documentation improvements
- New features that fit the project scope
- Integration examples showing real usage

## Code style

Follow the existing patterns in the repo. Keep functions small and focused. Prefer clarity over cleverness.

## Discussion

Open an issue before starting large changes so we can align on approach.
